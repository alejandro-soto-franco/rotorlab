# rotorlab

GA-first Rust math-animation engine. Renders explainer videos to mp4 via raw Vulkan + FFmpeg.

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](../LICENSE-APACHE)

**Status:** pre-release. v0.1.0 is the first published version, scheduled for the end of the 8-week MVP. Earlier 0.0.x versions ship to crates.io only as name-reservation placeholders if needed; for now this crate lives in the workspace but does not publish.

Depends on [`rotorlab-ga`](../rotorlab-ga/) for the geometric algebra core.
